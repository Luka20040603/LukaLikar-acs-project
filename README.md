# Tower Defense Game

A 2D Tower Defense game built in **Python** with **Pygame**, developed with the help of an AI coding agent (pi) for the Agentic Computer Science course at FRI.

## Project Goals

- Build a playable, bug-free Tower Defense game with:
  - Main menu and distinct game states (menu, playing, win, game-over)
  - A predefined enemy path and enemy spawning/movement
  - Placeable towers with different types, targeting and projectiles
  - Enemy health, player currency economy (buy/sell)
  - Multiple enemy waves with increasing difficulty
  - Player lives, win and lose conditions
  - HUD (money, lives, wave) and sound effects
- Keep the code simple, readable and maintainable, with a clear incremental commit history on Git/GitHub.
- Demonstrate an AI-assisted (agentic) development workflow: the agent plans, implements incrementally, tests and documents; the human reviews, decides on scope and commits.


### Demonstration Instructions

1. Start the game; you land on the **main menu**.
2. Start a new game to enter the playing state.
3. Enemies walk along the defined path in successive waves.
4. Click a buildable spot to place a tower (costs currency).
5. Towers automatically target enemies in range and fire projectiles.
6. Killing enemies earns currency; enemies reaching the end of the path reduce player lives.
7. Survive all waves to **win**; losing all lives means **game over**. Back to the menu from either end state.

(Instructions above describe the target behaviour; they will be finalized as the features are implemented.)

## Development Process

- Work is done incrementally, one feature at a time, with the code tested after each step.
- Commits are frequent, focused and use meaningful messages. (The human commits; the agent never commits without permission.)
- Session notes are kept in `docs/` at the end of each work session.
